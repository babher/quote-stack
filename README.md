# 引用栈 / Quote Stack

划词即存，带出处，一屏取用。

一个 Windows 桌面小工具：在 Edge 里选中文字按一次热键，就把这段文字连同来源和网址存进本地栈；
在任意程序里（Word、WPS、微信、记事本…）再按同一个热键，勾选几条按顺序插入到光标处。

- 平台：Windows 11 x64
- 形态：常驻小浮窗 + 右侧引用抽屉（C# WinForms，单 exe，零第三方依赖）
- 采集来源：仅 Microsoft Edge
- 网络：**不联网**。没有任何下载、上传、自动更新请求
- 数据：全部在本地 `%APPDATA%\quote-stack\`

## 版本

当前为 `v1`（首个可用版本）。

## 构建

需要系统自带的 .NET Framework 4 编译器（Windows 自带，无需安装 SDK）：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

在 `app/` 目录下双击 `BUILD.cmd`，它会：

1. 用上面的 `csc.exe` 编译 `QuoteStack.cs` 到 `dist\QuoteStack.exe`
2. 把 exe 复制到 `%LOCALAPPDATA%\qsapp\`

> **为什么复制到 `%LOCALAPPDATA%\qsapp\` 再运行**：本仓库目录带有 Low 完整性标签，
> 在仓库内直接运行会得到一个低完整性进程，模拟按键会被系统的 UIPI 机制**静默丢弃**
> （SendInput 仍返回"已接收"，但目标程序收不到键）。复制到用户目录运行即可避免。
> 这不是可选项，是这条产品路线成立的前提，详见 `p1-keyprobe/RESULT-keys.md`（未收录进本仓库）。

## 运行

双击 `app/RUN.cmd`（它会先结束旧实例，再从 `%LOCALAPPDATA%\qsapp\` 启动）。

启动后右下角出现一条 260×52 的小浮窗，显示已存条数与最新一条内容。

## 使用

一个热键，按"你当下在做什么"分流：

| 你在哪 | 你做了什么 | 按热键 |
|---|---|---|
| Edge 页面 | 选中了文字 | 存一条引用（小浮窗数字 +1，右侧弹 `+1`） |
| Edge 页面 | 没选中（只是点了输入框） | 弹出抽屉，进入插入模式 |
| 其它程序（Word / WPS / 微信…） | — | 弹出抽屉，插入目标＝该窗口 |

抽屉里：

- 窗口最小 320×360，可拖边缘缩放；**顶部 30px 标题条按住即可拖动整个抽屉**；放大/缩小后关掉抽屉，下次打开保持这个尺寸（记在 `config.json`）
- 点勾选框或按 `空格` 勾选，**右侧会显示序号**，插入顺序＝勾选顺序
- `↑` `↓` 移动光标行，`→` 展开/收起整条内容，`←` 收起
- 点条目右侧箭头也可展开；展开后能看到时间、来源，以及可点击复制的网址
- `Esc` 关闭抽屉
- 勾好后按**热键**插入（不是回车）；插入后抽屉保持打开，刚插入的条目自动取消勾选
- 插入成功会把内容放进剪贴板、按一次 `Ctrl+V`、然后**把剪贴板还原**成插入前的内容
- 插过的条目，meta 行会多出 `已引用`

抽屉底栏固定三个入口，从左到右（任何宽度下都不重叠，文字放不下时左侧提示语自动省略）：

- `清理已引用(N)` — 打开清理面板；没有已引用内容时变灰、点了不响应
- `删除 N 项` — 删除当前勾选的几条，二次确认后才删；没勾选时变灰
- `全选` — 一键勾选全部（全部已勾选时变成 `取消全选`）
- 三者都走同一套原子替换（先写临时文件再替换），删除不可恢复；删掉的条目会同时从 `used.ndjson` 里移除

清理已引用的内容（按"已插入过"批量删除，原方案保留）：

- 点抽屉底栏的 `清理已引用(N)`，或托盘右键 `清理已引用的内容…`
- 弹出的列表默认全选，取消不想删的，点 `删除选中` → 二次确认 → 删除
- 删除是**原子替换**（先写临时文件再替换），中途崩溃不会留下半个文件
- 删除不可恢复；删掉的条目会同时从 `used.ndjson` 里移除

## 配置

`%APPDATA%\quote-stack\config.json`

```json
{ "hotkey": "Alt+Shift+Q", "drawerW": "320", "drawerH": "360" }
```

**改热键不用再手改文件**：打开抽屉后左侧会浮出一个小圆形齿轮按钮，点它弹出设置面板。面板是**栏式（折叠）**的：现在只有「热键修改」一栏，右侧是展开箭头，点这一栏才展开录制区，其余位置先留空、以后再加别的设置：

- 展开后点一下输入框，直接按 `Ctrl+Alt+Q` 这样的组合（**按出来的、不是打出来的**），框里显示录到的键，栏名右侧同步显示当前值
- `取消` / `Esc` 关闭面板；`Esc` 在录制中只撤销这一轮录制
- `保存` —— 写入 `config.json`，下次启动生效（小条提示「热键已保存 · 重启后生效」）
- `保存并重启` —— 先**试注册**新组合：注册不上就当场提示并保留原热键，**不会去启动一个注定失败的实例**；注册得上才启动新实例，并等新实例在 `startup.log` 里写出 `hotkey-registered: <组合>` 才退出自己。新实例没起来会被关掉、原热键自动恢复
- 录制规则：至少一个修饰键（`Ctrl`/`Alt`/`Shift`）+ 主键 `A-Z`、`0-9`、`F1-F24`；**再点一次输入框会重新录制**（旧值保留到新组合录成为止）；`Esc` 取消（恢复这一轮录制前的值）、`Delete`/`Backspace` 清空；缺修饰键、不认识的键、单独的 `Win` 组合都会当场提示且**不写文件**

命令行/文件路径仍然可用（托盘「打开配置」或 `app/SETKEY.cmd`）：

- 默认写的是 `Alt+Q`，但本机该组合常被其它软件占用（`RegisterHotKey` 返回 1409）
- **冲突不再直接退出**：注册失败时按 `Alt+Shift+Q` → `Ctrl+Alt+Q` → `Ctrl+Shift+Q` → `Ctrl+Alt+1` 依次试，取第一个能注册的，把它写回 `config.json`，并在小条上提示「原热键被占用，已改用 X」。全都占着才弹框退出。日志分别记 `hotkey-register-failed: … err=1409`、`hotkey-fallback: 旧 -> 新`、`hotkey-fallback-written: 新`
- 支持格式：修饰键 `Alt`/`Ctrl`/`Shift`/`Win` + 主键 `A-Z`、`0-9`、`F1-F24`；必须带修饰键且不能只用 `Win`

## 数据位置

| 文件 | 内容 |
|---|---|
| `%APPDATA%\quote-stack\stack.ndjson` | 引用记录，一行一条 JSON（`id`/`ts`/`source`/`title`/`text`/`url`）；最多保留 500 条，超出后自动删除最旧的 |
| `%APPDATA%\quote-stack\used.ndjson` | 已插入过哪些引用（`ts`/`key`，`key` 即记录 `id`；v1 旧记录回退为文本哈希），供「清理已引用」使用；记录被删除时同步清理 |
| `%APPDATA%\quote-stack\config.json` | 热键配置（`hotkey`）与抽屉尺寸记忆（`drawerW`/`drawerH`，字符串形式） |
| `%APPDATA%\quote-stack\startup.log` | 启动与采集诊断，**只记计数与错误码，不记正文、不记网址、不记文件路径**；超过 512 KB 自动改名为 `startup.log.1`（只留一份）并重开新文件 |
| `%LOCALAPPDATA%\qsapp\QuoteStack.exe` | 安装后的程序本体 |

删除 `%APPDATA%\quote-stack\` 与 `%LOCALAPPDATA%\qsapp\` 即完成卸载（没有注册表项、没有自启项）。

## 已知限制

- 采集只支持 Edge；其它浏览器不支持（探测结论见历史文档）
- 剪贴板备份只做了纯文本：插入前如果你的剪贴板里有图片或富文本，还原后只剩纯文本格式
- 采集不到页面里的"前后 200 字上下文"（需要读页面 DOM，本路线拿不到）
- 网址读取依赖采集时按一次 `Ctrl+L` 读地址栏，个别页面偶尔读不到，此时该条只存来源不存网址
- 插入是否真的落进目标程序**无法自检**：个别程序（部分终端）可能不认模拟粘贴，此时内容已放进剪贴板，手按 `Ctrl+V` 即可
- 记录不去重、不做敏感内容过滤（密码、证件号选中后同样会被保存）
- 上限 500 条：最旧的先被删除（删除会连带清掉它的「已引用」标记）；每条采集有自己的 `id`，同一句话采两次是两条独立记录，删一条不会带走另一条
- 抽屉开着时新采集会自动刷新；但若从外部把 `stack.ndjson` 清空或独占锁住，抽屉会提示「刷新失败（文件被占用？）」并**继续显示旧内容**，直到关掉重开抽屉
